# CodeForge 命令框架 · 规格说明

> 对齐参考 spec 的 12 条命令 / Kind 三分类 / UI Protocol / 补全菜单,适配 CodeForge(prompt_toolkit)。

## 背景

CodeForge 的输入框是单一入口:所有回车提交都作为 user message 送进 Agent 走 LLM。现有 `tui/commands.py` 是最小分发器(名字→handler 两栏),缺少元数据、启动期冲突检测、/help、补全与 UI 抽象层。非对话操作(看状态/记忆/权限/会话/帮助)也要让 LLM 去做,浪费 token、行为不确定。

## 目标

- G1:12 条内置命令(/exit /plan /do /compact /resume /clear /help /status /memory /permission /session /review)收编进命令注册中心。
- G2:常用本地操作绕过 LLM,响应即时、不消耗 token、行为确定。
- G3:UI 控制抽象,handler 不直接持有 TUI App 引用,为后续 Skill 系统解耦。
- G4:注册中心驱动 /help 与未命中提示(单一信源);启动期检测名字/别名冲突立即终止启动。
- G5:输入 `/` 后实时候选补全,覆盖上/下/Tab/回车/ESC 全套键位。

## 功能需求

### 命令注册与分发

- **F1**:`Command` 元数据:名称(小写、去 `/`)、别名集合、一句描述、执行类型(Kind)、参数提示、是否隐藏、处理函数。
- **F2**:`Registry.register` 在启动期对名字与别名做冲突检测,重复即 `raise RuntimeError`(含冲突键),启动进程终止,不进入运行时。
- **F3**:分发器先判是否以 `/` 开头;是则本地分发,否则送 Agent。
- **F4**:命令名匹配大小写不敏感。
- **F5**:空输入/纯空白早返回,不参与分发。
- **F6**:未命中任何已注册名/别名时,输出引导使用 /help 的提示,不发 LLM。
- **F7**:带参数支持:命令带 `arg_hint`(如 /review 的「重点」)时,第一个空格后的内容作为参数传给 handler;不带 arg_hint 的命令,尾随参数按未命中处理(与参考 spec 一致,仅 /review 例外,见 N4 注)。

### 命令执行类型

- **F8**:每条命令显式声明 Kind 之一:`LOCAL`(纯本地)/ `UI`(影响界面)/ `PROMPT`(提示词)。
- **F9** `LOCAL`:只向用户输出信息,不修改对话历史、不改界面模式、不消耗 token。
- **F10** `UI`:可修改模式、清空/重建会话、退出进程、触发恢复,但不向对话历史追加 user 消息。
- **F11** `PROMPT`:向对话历史追加一条 user 消息(含命令产生的固定文本),立即触发一次 LLM 回合;该消息按与真实用户消息相同的方式持久化、对 LLM 可见。
- **F11a**:`UI` 与 `PROMPT` 命令仅在 idle 状态可执行,非 idle 时拒绝并提示「请等待当前任务完成」;`LOCAL` 命令任何状态可执行。

### 12 条内置命令

- **F12** `/exit`(UI):关闭进程,退出前通知 TUI 取消主 asyncio 任务(CancelledError),资源由 shutdown 钩子关闭。
- **F13** `/plan`(UI):切换权限模式到 PLAN,状态栏显示 `[PLAN]`。
- **F14** `/do`(PROMPT):先把模式切回 DEFAULT,再向对话注入执行指令文本(计划存在则含计划内容),立即触发回合。
- **F15** `/compact`(UI):手动触发上下文压缩,走既有压缩事件流推送进度。
- **F16** `/resume`(UI):打开历史会话列表,选中后从该会话最后一个 compact 标记之后恢复。
- **F17** `/clear`(UI):关闭当前会话存档 writer、开新会话(新 SessionContext + 新 writer)、清空内存消息、重置 token 计数与回合数;输出 notice 提示已开启新会话;旧会话 JSONL 保留,/resume 仍可见。
- **F18** `/help`(LOCAL):按名字典序输出每条可见命令「名字 + 描述」两列对齐。
- **F19** `/status`(LOCAL):按固定顺序输出 6 项:Mode / Tokens(in/out) / Tools / Memories / Model / Directory。
- **F20** `/memory`(LOCAL):输出已加载的项目层 + 用户层记忆文件名列表(只列文件名)。
- **F21** `/permission`(LOCAL):输出当前权限模式的字符串名。
- **F22** `/session`(LOCAL):输出当前会话存档文件路径与 session 标识。
- **F23** `/review`(PROMPT):向对话注入固定文本的「代码审查请求」,立即触发回合;支持 `/review <重点>` 把后缀追加到提示词末尾。

### 自动补全菜单

- **F24**:输入框首字符为 `/` 时菜单激活并实时显示候选;继续输入按当前输入对全部注册命令名做前缀匹配过滤。
- **F25**:菜单仅按命令名前缀匹配,不匹配别名、不匹配描述。
- **F26**:当前输入不再以 `/` 开头(含删空)时菜单立即关闭。
- **F27**:每条候选显示「命令名 + 描述」两列对齐。
- **F28**:`hidden=True` 的命令不出现在 /help 与补全菜单,但 dispatcher 仍能命中(为 Skill 系统预留)。
- **F29**:菜单激活期间 ↑/↓ 切换高亮项。
- **F30**:菜单激活期间 Enter/Tab 执行当前高亮命令;执行后菜单关闭、输入框清空。
- **F31**:ESC 关闭菜单,输入框内容保持不变。
- **F32**:菜单关闭时所有键位回到输入区默认行为。
- **F32a**:输入含换行时菜单不激活;激活后变多行则关闭。
- **F32b**:零匹配时显示「无匹配」提示行;回车走未命中分支,Tab/ESC 仅关闭菜单。

### UI 抽象层

- **F33**:handler 不持有 TUI 渲染类型;通过 `UI` 协议访问能力:打印消息、注入并发送 user 消息、切换模式、查询用量/模式/模型/目录/记忆文件名、关闭进程、打开会话列表、触发压缩、清空重建会话等。
- **F34**:协议只暴露命令实际需要的方法,不外露 TUI App 内部属性。
- **F35**:handler 签名仅依赖 `UI` 协议,不依赖具体 TUI 实现。

## 非功能需求

- **N1**:LOCAL 命令回车后主线程完成输出,无可观察延迟。
- **N2**:UI 命令的状态变更立即可见(模式标记下一帧生效)。
- **N3**:PROMPT 命令注入消息与真实用户消息不可区分:走相同对话历史追加、相同会话存档持久化路径。
- **N4**:/review 是唯一带参数的命令(你的明确需求);其余命令零参数,尾随按未命中。
- **N5**:补全菜单高度上限固定行数(8),候选超出可滚动。
- **N6**:补全菜单位于输入框下方、状态栏上方,不占用状态栏渲染区。
- **N7**:/help 与未命中提示的命令列表来自同一注册中心查询,无硬编码清单。
- **N8**:/status 6 字段渲染顺序固定,key/value 按列对齐。
- **N9**:/clear 后 /resume 能看到旧会话。
- **N10**:既有 /exit /plan /do /compact /resume 外部行为与实施前一致。
- **N11**:状态栏左右字段、模式徽章渲染保持现状。
- **N12**:/exit 前取消主 asyncio cancel scope,后台任务收到 CancelledError。

## 不做的事

- 不做用户自定义命令、命令热加载、动态生成提示词(除 /review 后缀)。
- 不做命令级权限控制(留给 Skill 系统)。
- /review 不读 git diff、不收集外部上下文。
- /memory 不展开内容、不提供编辑、不触发重载。
- /permission 不能修改模式、不能编辑规则。
- /session 不能切换或操作会话。
- /help 不分组、不显示别名、不支持详情子查询。
- 不支持鼠标点击补全候选项。

## 验收标准

- **AC1**:`/help` 输出字典序 12 行「命令名 + 描述」两列对齐。
- **AC2**:`/foobar` 输出引导 /help 的提示,不触发 LLM。
- **AC3**:`/Help` 大小写混合与 /help 一致。
- **AC4**:`/status` 输出 6 行 key:value,顺序固定。
- **AC5**:`/memory` 输出项目层+用户层记忆文件名列表。
- **AC6**:`/permission` 输出当前权限模式名。
- **AC7**:`/session` 输出会话存档路径与 session 标识。
- **AC8**:`/clear` 清空对话区、token 归零;再跑一轮后 /resume 能看到旧会话。
- **AC9**:`/review` 触发 AI 回复,会话存档新增 user 消息含「审查」;`/review 注意安全` 的提示词含「注意安全」。
- **AC10**:既有 /exit /plan /do /compact /resume 行为一致。
- **AC11**:输入 `/` 菜单激活显示 12 条候选。
- **AC12**:输入 `/s` 菜单仅显示 /session、/status。
- **AC13**:↑/↓ 切换高亮,Enter 执行所选。
- **AC14**:ESC 关闭菜单,输入框保留 `/s`。
- **AC15**:删除 `/` 后菜单立即消失。
- **AC16**:注册同名命令 → 启动立即终止并打印冲突名。
- **AC17**:tmux 内 /help → /status → /memory → /permission → /session → /review 全程不卡顿、输出正确、无错误日志。
